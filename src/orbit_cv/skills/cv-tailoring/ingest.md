# Skill: Candidate Profile Data Extraction

- Read the candidate's plain text CV directly from `/resumes/candidate_cv.txt`.
- Identify and extract core metadata:
  - Full Name
  - Primary Target Titles / Roles
  - Total Years of Professional Experience
  - Top 10 Primary Technical Skills
  - Key Domain Expertise & Tools
  - Key Work Experience Highlights & Impact Metrics
- Return a structured profile summary to the supervisor.
